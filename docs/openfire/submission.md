## Product description

Duress tests whether developer-owned webhook integrations preserve business correctness
under duplicate deliveries, retries and concurrency. It independently observes persisted
SQLite or PostgreSQL state, preserves failures as portable Failure DNA, reproduces them,
and compares an authorized correction against the vulnerable control.

The demonstrated defect is a genuine non-atomic check/wait/write in a controlled reference
application. A 2xx acknowledgment can coexist with duplicate fulfilments. An independent
PostgreSQL ticketing application exercises the external integration boundary. This is a
local-first developer beta; a hosted demo must execute bundled trusted targets only.
